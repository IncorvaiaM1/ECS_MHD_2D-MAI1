## Coherent Solutions at Re = 40
All at 128x128 resolution. The wavespeed is nan for upos and equilibria, and equal to the wavespeed for travelling waves. There are all the unique solutions (neglecting the shift-reflect symmetry). Some of the UPOs are duplicates when we allow for the shift-reflect symmetry.
